# Momentum Design System

## Visual Direction
Minimalist productivity tool using the **Clinical White** palette. The focus is on clarity, momentum (streaks), and low-friction interaction.

## Palette
- **Background**: #FFFFFF (Pure White)
- **Surface**: #F8FAFC (Subtle Grey)
- **Primary**: #2563EB (Action Blue)
- **Success**: #10B981 (Streak Green)

## Typography
- System default sans-serif (Inter style).
- Headings: Bold/700 for hierarchy.
- Body: Medium/400 for readability.

## Interaction
- **Primary Action**: Add button (FAB) at bottom-right.
- **List Interaction**: Toggle completion via check icon; card changes background color when done for immediate feedback.
