# Momentum Habit Tracker

A modern Android habit tracker built with Jetpack Compose and Room.

## Features
- **Daily Tracking**: Simple one-tap completion.
- **Streak System**: Track consistency over time.
- **Local Storage**: Data persists on device using Room Database.
- **Clean Design**: Minimalist "Clinical White" theme.

## Tech Stack
- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Local DB**: Room Persistence Library
- **Architecture**: MVVM with Flow/Coroutines

## Getting Started
1. Open in Android Studio.
2. Sync Gradle files.
3. Run on an emulator or physical device (Min SDK 26).
